## 一、档案借阅记录（后端）

### 1.1 整体说明

档案借阅记录功能由以下 4 个文件构成调用链：

```
Controller → Service → ServiceImpl → Mapper
```

Controller 继承 `BaseRestController`，自动获得 `/search`、`/insert`、`/delete`、`/deleteBatch`、`/update` 五个通用接口，在此基础上额外扩展了按用户 ID 查询借阅记录的自定义接口 `/getOne`，以及重写了模糊搜索条件 `getSearchQueryWrapper`。

### 1.2 代码清单

#### ① PhysicalArchivesRecordController.java 

路径：`stu_fms_web/src/main/java/com/captain/controller/PhysicalArchivesRecordController.java`

```java
package com.captain.controller;

import com.baomidou.mybatisplus.core.conditions.query.QueryWrapper;
import com.captain.common.BaseRestController;
import com.captain.common.Result;
import com.captain.entity.po.PhysicalBorrRecord;
import com.captain.service.PhysicalBorrRecordService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.util.Assert;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.util.List;

@RestController
@RequestMapping("/physical/archives/record")
public class PhysicalArchivesRecordController extends BaseRestController<PhysicalBorrRecordService, PhysicalBorrRecord> {

    @Autowired
    private PhysicalBorrRecordService physicalBorrRecordService;

    // 重写模糊搜索条件：按用户名模糊查询
    @Override
    protected QueryWrapper<PhysicalBorrRecord> getSearchQueryWrapper(String searchValue, PhysicalBorrRecord physicalBorrRecord) {
        QueryWrapper<PhysicalBorrRecord> physicalBorrRecordQueryWrapper = new QueryWrapper<PhysicalBorrRecord>();
        if (searchValue != null && !searchValue.isEmpty()) {
            physicalBorrRecordQueryWrapper.like("username", searchValue);
        }
        return physicalBorrRecordQueryWrapper;
    }

    // 通过用户id查询他的所有借阅记录
    @GetMapping("/getOne")
    public Result getByUsernameId(Long usernameId) {
        Assert.notNull(usernameId, "id为空");
        List<PhysicalBorrRecord> list = physicalBorrRecordService.findOneByusernameID(usernameId);
        return Result.success(list);
    }
}
```

**关键点：**
- `@RequestMapping("/physical/archives/record")` — 接口前缀
- `extends BaseRestController` — 继承通用 CRUD，无需手写分页/增删改方法
- `getSearchQueryWrapper` 重写 — 搜索时按 `username` 字段模糊匹配
- `@GetMapping("/getOne")` — 新增的自定义接口，按 `usernameId` 查询某用户的全部借阅记录

```java
package com.captain.mapper;

import com.baomidou.mybatisplus.core.mapper.BaseMapper;
import com.captain.entity.po.PhysicalBorrRecord;
import org.apache.ibatis.annotations.Param;
import org.apache.ibatis.annotations.Select;
import java.util.List;

public interface PhysicalBorrRecordMapper extends BaseMapper<PhysicalBorrRecord> {

    // 通过用户id查询借阅记录（注解SQL，无XML mapper文件）

}
```

## 三、改动总结

### 3.1 后端：档案借阅记录模块

| 文件 | 层级 | 改动内容 |
|------|------|----------|
| `PhysicalArchivesRecordController.java` | Controller | 继承 `BaseRestController` 获得通用 CRUD；重写 `getSearchQueryWrapper` 实现按用户名模糊搜索；新增 `GET /getOne` 接口按用户 ID 查询全部借阅记录 |
| `PhysicalBorrRecordService.java` | Service 接口 | 声明 `findOneByusernameID` 方法 |
| `PhysicalBorrRecordServiceImpl.java` | Service 实现 | 调用 Mapper 层方法返回借阅记录列表 |
| `PhysicalBorrRecordMapper.java` | Mapper | 使用 `@Select` 注解编写 SQL，查询 `physical_borr_record` 表中指定 `username_id` 的记录 |

**设计思路**：Controller 不重复编写分页/增删改，靠继承 `BaseRestController` 泛型基类复用；只对搜索条件做定制（按用户名模糊匹配），并额外加一个"按用户 ID 查全部借阅记录"的业务接口，供前端借阅状态页调用。

### 3.2 前端：活动/竞赛信息模块

| 文件 | 改动内容 |
|------|----------|
| `activity.vue` | 完整的单文件 Vue 组件，实现表格展示、分页、搜索、新增/修改弹窗、单行删除、批量删除、多图预览 |

**与后端接口对应关系**：

| 前端方法 | 请求路径 | 后端接口 |
|----------|----------|----------|
| `search()` | `GET /api/activity/search` | `ActivityController` 继承基类的 `/search` |
| `insertRow()` | `POST /api/activity/insert` | 继承基类的 `/insert` |
| `updateRow()` | `POST /api/activity/update` | 继承基类的 `/update` |
| `deleteRow()` | `POST /api/activity/delete` | 继承基类的 `/delete` |
| `deleteBatch()` | `POST /api/activity/deleteBatch` | 继承基类的 `/deleteBatch` |

**弹窗交互**：`openDetail(row)` 方法接收行数据，通过 `this.detail = {...row}` 浅拷贝赋值到弹窗表单；传空对象 `{}` 时为新增模式（`detail.id` 为 falsy，弹窗标题显示"新增"，底部按钮显示"新增"）；有 `id` 时为修改模式（标题显示"修改"，按钮显示"保存"）。弹窗由 `showDetail` 布尔值控制 `el-dialog` 的 `visible` 属性。
